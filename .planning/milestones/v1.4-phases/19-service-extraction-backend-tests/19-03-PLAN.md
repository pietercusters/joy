The class needs:

1. __init__(self, projects: list[Project] | None = None):
   - `self._projects: list[Project] = projects or []`

2. Property `projects -> list[Project]`: read access to project list

3. `set_projects(self, projects: list[Project]) -> None`:
   Replace the internal list (used after loading from disk)

4. `create_project(self, name: str, repo: str | None = None, branch: str | None = None, default_open_kinds: list[str] | None = None) -> Project`:
   - Raises ValueError if name already exists in self._projects
   - Creates Project(name=name, repo=repo)
   - If branch: appends ObjectItem(kind=PresetKind.BRANCH, value=branch)
   - Appends to self._projects
   - Returns the new Project

5. `add_object(self, project: Project, kind: PresetKind, value: str, default_open_kinds: list[str] | None = None) -> ObjectItem`:
   - Creates ObjectItem(kind=kind, value=value, open_by_default=kind.value in (default_open_kinds or []))
   - Appends to project.objects
   - Returns the new ObjectItem

6. `find_project(self, name: str) -> Project | None`:
   - Returns first project with matching name, or None

7. `has_project(self, name: str) -> bool`:
   - Returns True if project with name exists

8. `build_archived(self, project: Project) -> ArchivedProject`:
   - Creates ArchivedProject with current ISO timestamp
   - Returns the ArchivedProject (does NOT remove from list — app.py handles that)

9. `remove_project(self, project: Project) -> bool`:
   - Removes project from self._projects by identity
   - Returns True if removed, False if not found
