Create src/joy/pane_coordinator.py with a PaneCoordinator class. CRITICAL: this module must import ZERO from textual.*.

The class needs:

1. An __init__ accepting no arguments. State: `self._is_syncing: bool = False`

2. A `syncing` context manager (using contextlib.contextmanager) that sets `_is_syncing = True` on enter and `False` on finally. This replaces the manual try/finally pattern in each sync method.

3. A `@property is_syncing` that returns the flag value.

4. Three sync methods matching the current app.py logic:

   `sync_from_project(self, project, rel_index, wt_pane, term_pane)`:
   - Gets worktrees from rel_index.worktrees_for(project)
   - If worktrees: calls wt_pane.sync_to(wt.repo_name, wt.branch) on first; if not matched, wt_pane.clear_selection()
   - Else: wt_pane.clear_selection()
   - Gets terminals from rel_index.terminals_for(project)
   - If terminals: calls term_pane.sync_to(terminals[0].session_name); if not matched, term_pane.clear_selection()
   - Else: term_pane.clear_selection()
   - Wraps in self.syncing context manager

   `sync_from_worktree(self, worktree, rel_index, project_list, detail_pane, term_pane)`:
   - Gets project from rel_index.project_for_worktree(worktree)
   - If project found: project_list.sync_to(project.name), detail_pane.set_project(project, ...), sync terminal
   - Else: term_pane.clear_selection()
   - Wraps in self.syncing context manager

   `sync_from_session(self, session_name, rel_index, project_list, detail_pane, wt_pane)`:
   - Gets project from rel_index.project_for_terminal(session_name)
   - If project found: project_list.sync_to(project.name), detail_pane.set_project(project, ...), sync worktree
   - Else: wt_pane.clear_selection()
   - Wraps in self.syncing context manager

Type annotations use Protocol types from joy.ports (SyncablePane) for pane parameters where possible, but the detail_pane and project_list have different signatures so use duck typing or define minimal protocols inline. PREFERRED: Use plain type hints with the actual method signatures expected (sync_to, clear_selection, set_project) and document via docstrings. Do NOT import from joy.widgets.
